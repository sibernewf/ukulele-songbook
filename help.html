Welcome to the Ukulele Songbook

The Ukulele Songbook brings your songs, chord diagrams, practice tools and original TAB arrangements together in one easy-to-use place.

Whether you are learning your first song, preparing for a club session, practising at home or writing a melody arrangement, the Songbook is designed to help you spend less time organising music and more time playing it.

What you can do

  • Learn ukulele step by step in the new Ukulele Academy.
  • Browse and search your song collection.
  • Open songs with lyrics, chords, strumming notes and TAB.
  • Use auto-scroll while your hands stay on the instrument.
  • Practise with the built-in metronome and practice tools.
  • Create, save and edit your own TAB arrangements.
  • Build set lists for rehearsals and performances.
  • Print songs, arrangements and the fretboard note chart.
New here? Begin with Getting Started, then open a favourite song and explore the controls at your own pace.

Getting Started

This quick guide takes you from opening the Songbook to playing and printing your first song.

Open and play a song

  1. Find a song. Use the search box or browse the song list in the left menu.
  2. Open it. Select the song title to display the song in the main reading area.
  3. Check the chords. Review the chord names and diagrams before you begin.
  4. Adjust the text. Use A− or A+ if you need smaller or larger text.
  5. Start auto-scroll. Choose a comfortable speed, then start scrolling when you are ready to play.
  6. Pause when needed. Stop or pause auto-scroll to repeat a difficult section.

Print a song

  1. Open the song you want to print.
  2. Select the available print option.
  3. Check the preview and page orientation.
  4. Print or save the result using your device's print window.

Create your first arrangement

  1. Open TAB Composer.
  2. Enter a title and other song details.
  3. Add measures and enter chords, TAB notes and lyrics.
  4. Review the live preview.
  5. Save the arrangement to My Songs.
Tip: Start with a short chorus or melody. A small first arrangement is easier to check and edit.

Using the Songbook

The main Songbook screen is where you find, open and play songs. The menu provides access to the library and tools, while the main area displays the selected song.

Find a song

  1. Type part of the song title or artist name into the song search box.
  2. Review the matching songs.
  3. Select a title to open it.
  4. Clear the search to return to the complete song list.

Read the song display

  • Chord names appear near the lyrics or musical section where they are played.
  • Chord diagrams show the finger positions for the chords used in the song.
  • TAB lines show which fret to play on each ukulele string.
  • Strumming information may appear when it has been included with the song.
  • Notes and instructions may explain tuning, capo position, repeats or performance ideas.

Make more room for the song

Select Minimise menu to collapse the left menu and give the song more screen space. Select the control again to restore the menu.

Use alternate tunings

Some arrangements use a tuning other than standard G–C–E–A. When an alternate tuning is selected or supplied, the string labels in the arrangement show the tuning that should be used.

Tip: Check the tuning before playing any arrangement containing unfamiliar string labels.

My Songs

My Songs contains arrangements you create and save in the Songbook. You can reopen them, continue editing them, print them or remove them when they are no longer needed.

Save a new arrangement

  1. Create the arrangement in TAB Composer.
  2. Review the title, chords, notes, lyrics and preview.
  3. Select Save to My Songs.
  4. Open My Songs and confirm that the new song appears.

Edit an existing arrangement

  1. Open My Songs.
  2. Select the arrangement you want to change.
  3. Choose the edit option to reopen it in TAB Composer.
  4. Make your changes and save the arrangement again.

Delete an arrangement

  1. Open the arrangement from My Songs.
  2. Select Delete.
  3. Confirm the deletion when asked.
Important: Deleting a song removes that saved arrangement. Check the title carefully before confirming.

Set Lists

Set Lists help you group songs for a rehearsal, club meeting or performance and keep them in the order you plan to play them.

Create a set list

  1. Open the Set Lists section.
  2. Create a new set list and give it a clear name.
  3. Add the songs you want to include.
  4. Arrange the songs in performance order.
  5. Save the set list.

Use a set list

  1. Open the required set list.
  2. Select the first song.
  3. Move through the list as you rehearse or perform.
  4. Return to the set list whenever you need to choose another song.
Tip: Give set lists descriptive names such as “Friday Club – August” or “Christmas Performance”.

Practice Mode

Practice Mode provides a focused place to work on songs and musical skills without changing the song itself.

Start a practice session

  1. Open Practice Mode from the menu.
  2. Choose the song, exercise or practice item you want to work on.
  3. Set a comfortable pace.
  4. Play the section slowly and repeat it as needed.
  5. Increase the pace only after the notes and rhythm feel comfortable.

Practise difficult sections

  • Work on only one or two measures at a time.
  • Separate chord changes from strumming until both feel comfortable.
  • Practise melody TAB without accompaniment before combining parts.
  • Use the metronome to keep the timing even.
Tip: Several short, focused practice sessions are often more useful than one long session.
Related topics: Metronome · TAB Techniques · Using the Songbook

Metronome

The metronome provides a steady beat so you can practise rhythm and gradually build speed.

Use the metronome

  1. Open the metronome controls.
  2. Choose a tempo in beats per minute (BPM).
  3. Start the metronome and listen for several beats.
  4. Begin playing in time with the clicks.
  5. Stop the metronome when you finish or need to adjust the tempo.

Choose a useful tempo

Begin slowly enough to play accurately. When you can repeat the section cleanly several times, increase the BPM by a small amount.

Tip: Accuracy comes before speed. A slow, even performance is more useful than a fast, uneven one.

TAB Composer

TAB Composer lets you build an arrangement measure by measure. You can enter chords, ukulele TAB, lyrics and alternate tuning labels, then preview, save and print the result.

Create an arrangement

  1. Open TAB Composer. Start a new arrangement or edit one from My Songs.
  2. Enter the song details. Add a clear title and any other available information.
  3. Choose the tuning. Keep standard G–C–E–A or enter the tuning required by the arrangement.
  4. Add measures. Create enough measures for the section you are entering. More can be added later.
  5. Add chords. Enter a chord on the beat where the chord begins. It does not need to be repeated until it changes.
  6. Add TAB notes. Enter fret numbers or supported technique notation in the appropriate string and beat cells.
  7. Add lyrics. Place words or syllables where they best match the beat.
  8. Check the preview. Confirm that chord changes, notes, lyrics and measure spacing look correct.
  9. Save the arrangement. Use Save to My Songs so it can be reopened later.

Edit measures

  • Add a measure when the arrangement needs more space.
  • Delete an unwanted measure using its delete control.
  • Check the preview after adding or deleting measures.

Enter notes

A cell can contain a fret number such as 3, a muted note such as x, or a supported TAB technique such as 5/7. See TAB Techniques for the complete notation guide.

Tip: Build and preview a few measures at a time. Small checks make mistakes easier to find.

TAB Techniques

TAB Composer supports common ukulele and guitar-style tablature symbols. Enter the notation directly into a TAB note cell.

NotationTechniqueHow to play it
5/7Slide upPlay fret 5, keep pressure on the string and slide up to fret 7.
7\5Slide downPlay fret 7 and slide down to fret 5 without lifting the finger.
5h7Hammer-onPlay fret 5, then sound fret 7 by placing another finger firmly onto the string.
7p5Pull-offPlay fret 7, then pull the finger away so the note at fret 5 sounds.
7b8BendPlay fret 7 and bend the string until it reaches approximately the pitch of fret 8.
8r7Bend releaseBegin with the string bent to the higher pitch, then release it back to fret 7.
5~VibratoPlay fret 5 and gently vary the pitch by rocking the fretting finger.
xMuted noteTouch the string lightly so it produces a short percussive sound rather than a clear pitch.

Enter a technique

  1. Select the TAB cell where the technique begins.
  2. Type the complete notation, such as 5h7.
  3. Check the preview to make sure it fits clearly in the measure.
  4. Play the passage slowly before bringing it up to tempo.
Tip: Technique symbols explain how notes connect. They do not replace careful listening and slow practice.

Printing and Exporting

The Songbook can produce a clean printed song sheet and provides additional ways to copy or export an arrangement.

Print an arrangement

  1. Open the song or arrangement you want to print.
  2. Select the print option.
  3. Review the print preview.
  4. Choose portrait orientation when using the standard arrangement layout.
  5. Check that all measures, chord diagrams and text fit on the expected pages.
  6. Print the page or choose the option to save it as a PDF.

Export as text

  1. Open the arrangement in TAB Composer.
  2. Select Export TXT.
  3. Save the text file when prompted.

Copy the preview

  1. Open the arrangement preview.
  2. Select Copy Preview.
  3. Paste the copied text into a message, note or document.
Printing tip: Print preview is the best place to catch clipped lines or an unwanted extra page before using paper.

Fretboard Note Chart

The Fretboard Note Chart shows the note found at each fret on each ukulele string. It is useful for learning the neck, finding melody notes and understanding how TAB relates to note names.

Open and use the chart

  1. Open the Fretboard Notes or note-chart tool.
  2. Locate the string you are using.
  3. Follow the string across to the required fret.
  4. Read the note name shown at that position.

Print the chart

  1. Open the complete chart.
  2. Select its print option.
  3. Check that the complete fretboard fits on the first page.
  4. Print or save it as a PDF for reference.
Tip: Learn a few notes at a time, beginning with the open strings and the notes used in your current song.

Frequently Asked Questions

How do I find a song quickly?

Use the song search box and enter part of the title or artist name. Select a matching title to open it.

What is the difference between the main song library and My Songs?

The main library contains the songs supplied with the Songbook. My Songs contains arrangements you create and save yourself.

How do I add a new song?

Open TAB Composer, enter the song information and arrangement, then select Save to My Songs.

Can I edit a song later?

Yes. Open it from My Songs, choose the edit option, make your changes in TAB Composer and save it again.

How do I delete one of my songs?

Open the song from My Songs, select Delete and confirm the deletion.

Why is a chord diagram not showing?

Check that the chord name is entered correctly. Unusual chord names or fingerings may not have a matching diagram available.

Can I use alternate tunings?

Yes. TAB Composer allows the arrangement's string labels to show a tuning other than standard G–C–E–A.

What do symbols such as 5h7 and 5/7 mean?

They describe playing techniques. See TAB Techniques for a complete table and playing instructions.

Can I print my own arrangements?

Yes. Open the arrangement and use the print option. Review the preview before printing or saving as a PDF.

How do I make the song use more of the screen?

Select Minimise menu to collapse the left menu. Select it again to restore the menu.

What should I do if auto-scroll is too fast?

Pause or stop it, reduce the speed, then restart when you are ready.

Can I search this Help Centre?

Yes. Enter a word or phrase in Search Help. For example, search for printing, tablature, lyrics or metronome.

About the Ukulele Songbook

The Ukulele Songbook is a practical collection of tools for ukulele players. It combines a song library with chord diagrams, auto-scroll, practice features, set lists, TAB composition and print-friendly arrangements.

It is designed for learning, home practice, ukulele clubs and performances. The emphasis is on keeping useful musical information together and making it easy to read while playing.
